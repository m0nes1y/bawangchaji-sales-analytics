# 霸王茶姬销量数据分析可视化平台

一个面向茶饮零售场景的**销量数据分析与可视化平台**，覆盖 15 座城市、8 款在售产品的 2025 全年销售数据，从天气、季节、节假日、营销活动、会员、折扣等多维度揭示业务规律，并自动生成可解释的分析结论。

> 数据均为教学/演示用途的**模拟数据**（由 `generate_data.py` 固定随机种子生成、可复现），仅用于数据分析方法与实践，**不代表品牌真实经营情况**。

## 功能特性

- **KPI 总览**：总销量、总营收、记录条数、平均会员占比
- **可视化矩阵**：月度趋势（双轴）、产品排名（**销量/营收 一键切换**）、单品经营明细表、产品月度趋势（多线）、品类占比、城市排名、季节对比、天气影响、营销活动效果、城市×产品热力图、节假日对比、折扣分析、**产品关联分析（Apriori）表**、**中国销量分布地图（可交互）**
- **交互筛选**：支持按「城市 / 品类 / 产品 / 月份（时间维度）」联动筛选，所有图表与结论实时刷新；**地图点击城市气泡可一键联动筛选全看板**
- **分析结论自动生成**：后端基于当前数据动态计算 11 条业务洞察（非硬编码），覆盖区域表现、产品结构、季节规律、价格策略、天气影响、节假日效应、会员运营、增长机会、价格弹性、会员分层与产品关联
- **高级分析模块（指标体系 / 统计检验 / 预测建模）**：后端落地一整套数据分析硬技能，直接佐证简历能力，详见下文「分析方法论」——
  - **业务指标体系**：从 0 到 1 定义核心指标与统计口径（总销量、客单价、连带率、会员复购率等），输出指标字典
  - **异动监测**：日销量时序上 3σ + 环比阈值标记异常日，并自动定位根因（节假日 / 营销活动 / 恶劣天气）
  - **显著性检验**：手写 Welch t 检验（方差不齐），验证节假日 / 折扣 / 天气等差异是否统计显著
  - **价格弹性**：按产品做组内固定效应（去均值）的双对数回归，消除品类结构干扰，得到干净的自身价格弹性
  - **时间序列预测**：加法季节分解（趋势 + 月度季节项）外推未来 3 个月销量，附 95% 置信区间
  - **RFM 会员分层**：对 6000 条会员样本做 R/F/M 五分位分层，输出 5 段人群规模、人均消费与流失率
  - **会员复购 / 流失预测**：GBDT 监督式建模（5 折交叉验证），量化召回优先级排序特征
- **工程化**：CSV 入库带数据校验（脏数据跳过并计数）、查询结果缓存、环境变量配置、统一 JSON 错误返回

## 核心流程

平台遵循「数据生成 → 入库 → API 服务 → 前端渲染 → 交互联动」的清晰链路：

```mermaid
flowchart TD
    subgraph 数据层
      A1[generate_data.py<br/>固定种子生成交易级数据] --> A2[(bawangchaji_sales.csv)]
      A2 --> A3[init_db 校验入库<br/>脏数据跳过并计数]
      A3 --> A4[(SQLite sales 表)]
    end
    subgraph 服务层
      A4 --> B1[Flask REST API<br/>筛选: 城市/品类/产品/月份]
      B1 --> B2[门店-日聚合<br/>天气/节假日/折扣/活动/会员]
      B1 --> B3[动态洞察计算<br/>11 条业务结论]
    end
    subgraph 展示层
      B1 --> C1[ECharts 看板<br/>12+ 图表 + 中国地图]
      C1 --> C2[联动筛选<br/>点击地图城市气泡]
      C2 --> B1
    end
```

- **数据层**：`generate_data.py` 以固定随机种子生成约 3.3 万行交易级数据（含真实订单篮 `订单号`），保证结果可复现；`init_db` 入库时做字段校验，脏数据跳过并计数。
- **服务层**：Flask 提供 REST API，所有查询按「门店-日」聚合（避免交易明细行均值被摊平），并基于当前数据**动态计算 11 条业务洞察**（非硬编码），带查询缓存与统一错误返回。
- **展示层**：前端以 ECharts 渲染 12+ 张图表 + 可交互中国地图；筛选栏（城市/品类/产品/月份）与地图点击均可联动刷新全看板。

## 运行方式

```bash
# 1. 创建并激活虚拟环境（可选但推荐）
python -m venv .venv
source .venv/Scripts/activate      # Windows: .venv\Scripts\activate

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务
python backend/app.py

# 4. 浏览器打开
#    http://localhost:8080
```

> 首次启动会自动读取 `data/bawangchaji_sales.csv` 并写入 SQLite；如需重新导入，删除 `backend/bawangchaji.db` 后重启即可。
> **若 `data/bawangchaji_sales.csv` 缺失，后端会自动调用 `backend/generate_data.py`（固定随机种子，结果可复现）重新生成**，无需手动准备数据。
> 可用环境变量覆盖：`PORT`（默认 8080）、`FLASK_DEBUG=1`（开启调试模式）。
> 会员建模样本 `data/members.csv` 缺失时同样会由 `backend/generate_members.py` 自动生成（固定种子），因此**克隆仓库后无需手动准备任何数据即可完整运行**，包括 RFM 与流失预测模块。

## 核心分析结论（2025 全年，基于当前数据动态计算）

以下结论由平台基于数据**动态计算**，可直接作为面试中的业务理解素材：

1. **区域表现**：营收冠军为上海，约为末位青岛的 2.4 倍，区域差异显著，下沉市场提升空间大。
2. **产品结构**：王牌单品「伯牙绝弦」贡献约 22.9% 营收，是基本盘核心。
3. **季节规律**：夏季为销量旺季、秋季最低——热饮与冷饮结构使夏季反超。
4. **价格策略**：折扣对单店日均销量正向拉动（整体 +12.5%），折扣力度每加深 10% 单店日均约 +17.2%；说明在促销节点合理让利可有效放大销量。
5. **天气影响**：晴天单店日均最高（34 杯），雷阵雨天最低（23 杯），可结合天气预报做动态排班与库存预警。
6. **节假日效应**：节假日单店日均较工作日 +59.7%，大促节点（五一 / 春节 / 清明）显著放量，活动是核心增量来源。
7. **会员运营**：会员占比与销量正相关（r=0.51），会员占比高层门店日均 38 杯、低层仅 20 杯，提升会员拉新与复购对单店产出有显著杠杆。
8. **增长机会**：同一王牌单品在不同城市渗透差异大（如伯牙绝弦在苏州偏弱），可针对性本地化推广。

## 分析方法论（代码即验证）

「高级分析」模块并非截图装点，而是后端用真实统计 / 机器学习方法对数据算出结果，前端如实呈现。**仓库代码本身就是简历能力的可验证证据**——面试官 clone 后 `python backend/app.py` 即可复现以下全部结论。各模块方法、关键结果与对应简历技能如下：

| 模块 | 方法 | 当前数据下的真实结果 | 佐证简历技能 |
| --- | --- | --- | --- |
| **业务指标体系** | 从 0 到 1 定义核心指标 + 统计口径字典 | 11 项指标：总销量 44,658 杯 / 总营收 ¥800,207 / 客单价 ¥44.3 / 连带率 2.47 杯·单⁻¹ / 会员复购率 88.9%（覆盖 15 城·15 店·8 品·4 类） | 从 0 到 1 搭建业务指标体系 |
| **异动监测** | 日销量时序 3σ + 环比阈值（\|Δ\|≥30%）双判据，自动归因 | 精准捕获春节 / 五一等节假日放量（z 最高 3.75）、雷阵雨天气缩量等真实信号 | 3σ + 环比阈值异动监测 |
| **显著性检验** | 手写 Welch t 检验（方差不齐，scipy `ttest_ind(equal_var=False)`） | 节假日 vs 非节 p=2.3e-14（日均 +16.5 杯，95%CI[12.9,20.1]）；高折扣 vs 低折扣 p=6.1e-11；晴天 vs 雷阵雨 p=7.2e-30——差异均统计显著 | 手写 Welch t 检验 / 显著性验证 |
| **价格弹性** | 门店-日·产品级 双对数回归 + 组内固定效应（按产品去均值消除品类结构干扰） | 自身价格弹性 ≈ **-1.31**（p<0.001, n=8,792），负值符合"价高量低"直觉 | 价格弹性 / 回归建模 |
| **时间序列预测** | 月度总销量 加法季节分解（趋势 + 月度季节项）外推 + 95% 置信区间 | 旺季（8 月）季节项最高，模型捕捉季节反弹；未来 3 月预测带 ±~530 杯置信带 | 趋势 / 季节性预测 |
| **RFM 会员分层** | 6000 条会员样本 R/F/M 五分位（pandas `qcut`）组合分段 | 高价值(冠军)912人/流失率1.2%、忠诚1227/11%、潜力1250/13.6%、新客一般1196/19.1%、流失风险1415/34.6% | RFM 用户分层 |
| **会员复购 / 流失预测** | GBDT（sklearn）二分类 + 5 折交叉验证 | **AUC=0.849、准确率=0.872**（基线 0.828，+4.4pp）、F1=0.538；首位特征"最近购买间隔"重要性 0.80 | GBDT / XGBoost 用户流失预测建模 |

> 以上数值由平台基于当前数据**动态计算**，随筛选条件实时变化；本表为「全部数据」下的结果快照。

> **关于产品关联分析（Apriori）的数据说明**：数据为**交易级模拟数据**（约 3.3 万行），**15 个城市 = 15 个门店，每个门店常备 6/8 款产品**，并引入真实「订单（购物篮）」维度（`订单号` 字段，单笔订单含 1~4 款产品）。平台以订单为最小单元真实计算支持度 / 置信度 / 提升度：提升度 >1 表示互补搭配（如 青柑普洱×鸭屎香柠檬茶 1.45、桃桃乌龙×茉莉雪芽 1.39、伯牙绝弦×桂花弄 1.23），<1 表示替代关系（如 桂花弄×茉莉雪芽 0.38）；结果表以颜色标注「关系（互补/替代/中性）」列。数据由 `backend/generate_data.py` 固定随机种子生成，可复现；**按「单品」筛选时购物篮退化为单一产品会无数据（前端会提示原因）**，其余维度均正常出结果。
